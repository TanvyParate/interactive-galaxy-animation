# 🌌 Interactive Galaxy Animation

An eye-catching space-themed animation built using **HTML**, **CSS**, and **Vanilla JavaScript** — no external libraries used! ✨  
This project features interactive moving dots, twinkling stars, a star cursor trail, and a mouse-repel effect.

---

## 🚀 Features

- **Interactive Dots**: Dots float around and repel when the mouse gets close.
- **Twinkling Star Field**: Background stars with parallax and subtle twinkle effect.
- **Custom Star Cursor**: A trail of glowing stars follows your cursor.
- **Mouse Repel Effect**: Dots dynamically move away when the mouse approaches.

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (ES6+)
- No libraries or frameworks used.
